# BioInfo AI Studio — Selected Work

A public showcase of two live BioInfo AI Studio projects: an evidence-linked learning workspace and a structured valuation ledger. These examples show how business requirements can become accessible tools with explicit sources, clear output and documented limits.

**Project lead:** Jonathan Rapisarda, MBA. The work was developed with AI-assisted engineering and collaborators where appropriate.

## Approach

The projects share a practical design principle: make it possible to follow a result back to its inputs and understand what remains uncertain. The interface should support a person's decision, not conceal the assumptions behind it.

For LESSONS, users choose material they are authorized to use, explore connections among excerpts and generate an export. The built-in sample is fictional. For Ledger, the public table presents an itemized view of estimates and distinguishes unrecorded costs from zero.

## Scope of this showcase

This repository is a curated portfolio, not the complete Studio source or an installation package. It includes documentation and links to public examples; it does not contain customer data, access credentials or private workspace content.

LESSONS currently uses deterministic synthesis. The public workspace does not claim independent verification of source statements, and model-connected synthesis is identified as pending on the product page. The Ledger presents estimates and an internal accounting unit, not revenue, a cash balance or a business appraisal. See the linked pages for current functionality and disclosures.
